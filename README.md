# 💰 Expense Tracker App

A clean, responsive mobile application built to help users log, categorize, and monitor daily personal expenses with real-time budget tracking and local offline persistence.

---

## 🚀 Key Features

* **Instant Expense Logging:** Add expenses with amount, category, date, and custom notes in seconds.
* **Category Breakdown:** Group spending across categories (Food, Travel, Bills, Shopping, Entertainment).
* **Local Offline Storage:** Full offline functionality—data persists reliably on device memory.
* **Visual Summary:** View total daily and monthly expenditure at a glance.
* **CRUD Operations:** Easily edit or delete previous transaction records.

---

## 🛠️ Tech Stack

* **Framework:** Flutter / Dart
* **Local Storage / Database:** SQLite / Shared Preferences
* **State Management:** Provider / setState
* **Tools:** Android Studio, VS Code, Git
